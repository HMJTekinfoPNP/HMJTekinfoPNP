# Panduan Berkontribusi

Terima kasih atas kontribusi Anda untuk proyek-proyek HMJTekinfo. Kami menerima perbaikan bug, dokumentasi, peningkatan aksesibilitas, dan fitur yang selaras dengan kebutuhan organisasi.

## Sebelum memulai

- Baca README dan panduan lokal pada repositori tujuan.
- Cari issue atau pull request yang sudah ada agar pekerjaan tidak duplikat.
- Untuk perubahan besar, buka issue terlebih dahulu agar pendekatan dapat didiskusikan.
- Laporkan kerentanan keamanan secara privat sesuai [SECURITY.md](SECURITY.md), bukan melalui issue publik.

## Alur kontribusi

1. Fork repositori atau buat branch dari branch default dengan nama yang deskriptif.
2. Buat perubahan yang kecil, fokus, dan mudah ditinjau.
3. Jalankan pengujian, pemeriksaan format, atau build yang dijelaskan oleh repositori tersebut.
4. Gunakan pesan commit yang singkat dan menjelaskan tujuan perubahan.
5. Buka pull request menggunakan template yang tersedia dan tautkan issue terkait bila ada.

## Standar pull request

- Jelaskan masalah, solusi, dan cara perubahan diuji.
- Sertakan tangkapan layar atau contoh bila perubahan memengaruhi antarmuka.
- Jangan menambahkan rahasia, token, data pribadi, atau berkas yang tidak relevan.
- Tanggapi masukan peninjauan secara terbuka dan perbarui PR bila diperlukan.

Dengan berkontribusi, Anda setuju untuk mengikuti [Kode Etik](CODE_OF_CONDUCT.md).
